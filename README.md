This repository contains Python codes that accompany the paper:
Naghibzadeh, S. Kiana, Anthony Rollett Noel Walkington, and Kaushik Dayal. "Accretion and ablation in deformable solids using an Eulerian formulation: A finite deformation numerical method.", Journal of the Mechanics and Physics of Solids (2025).
https://doi.org/10.1016/j.jmps.2025.106076

The codes implement simulations of surface growth phenomena using the Firedrake FEM package. They cover three different examples from the paper:

1. Non Normal Growth with Constant Growth Inclination
2. Non Normal Growth with Time-Dependent Growth Inclination
3. Pressure Melting
